\## Lab Topic

Construction for Reuse: Interfaces, Generics, and Contracts



\## Objective

To apply software engineering principles by designing reusable software components using interfaces, generics, dependency injection, and contract integrity.



\## Task 1 – Black-Box Reuse

\- Created PaymentMethod interface.

\- Implemented CreditCardPayment and JazzCashPayment.

\- Created EcommerceCart using constructor-based dependency injection.

\- Demonstrated dynamic payment processing.



\## Task 2 – Generics

\- Created a generic DataBox<T> class.

\- Stored student name using DataBox<String>.

\- Stored student ID using DataBox<Integer>.

\- Demonstrated compile-time type safety.



\## Task 3 – Liskov Substitution Principle

\- Created Rectangle and Square classes.

\- Demonstrated the inheritance problem.

\- Fixed the design using a common Shape interface.

\- Created RectangleShape and SquareShape classes.



\## Task 4 – Reusable Ordering Algorithms

\- Created Student class with rollNo and cgpa.

\- Implemented Comparable<Student> for ascending roll number sorting.

\- Implemented CgpaComparator using Comparator<Student>.

\- Demonstrated descending CGPA sorting.
